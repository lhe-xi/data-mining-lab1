## 获取仓库

```powershell
git clone https://github.com/lhe-xi/data-mining-lab1.git
cd data-mining-lab1
```

进行实验一时先执行 `cd lab1`，再按照该目录的说明配置环境并运行。仓库地址保持不变，各次实验分别维护自己的依赖、图表和运行记录。
